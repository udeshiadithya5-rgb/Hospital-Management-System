#  Hospital Management System

##  Overview
A comprehensive Hospital Management System implemented in Java using fundamental data structures. This application manages patient records, emergency queues, treatment history, and patient visit histories.

##  Data Structures Used

### 1.  Binary Search Tree (BST)
- **Purpose**: Patient Records Management
- **Operations**: Insert, Search, Delete, In-order Traversal
- **Key**: Patient ID
- **Time Complexity**: O(log n) average

### 2.  Queue (FIFO)
- **Purpose**: Emergency Patient Queue
- **Operations**: Enqueue, Dequeue, Display, Peek
- **Principle**: First-In, First-Out
- **Use Case**: Managing waiting patients

### 3.  Stack (LIFO)
- **Purpose**: Treatment History
- **Operations**: Push, Pop, Peek, Display
- **Principle**: Last-In, First-Out
- **Use Case**: Recent treatment records

### 4.  Singly Linked List
- **Purpose**: Patient Visit History
- **Operations**: Add, Remove, Search, Display
- **Structure**: Node-based with head pointer
- **Use Case**: Each patient's visit history

##  Features
-  Add, search, and delete patient records
-  Manage emergency waiting queue
-  Track treatment history
-  Maintain patient visit history
-  In-order display of patients
-  User-friendly menu interface
-  Sample data for demonstration
